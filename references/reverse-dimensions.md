# 全场景维度拆解表 (Reverse Dimensions)

本文件是 Step 1「看图拆维」的权威参考。每个场景给出「维度 → 观察要点 → 关键词示例（中英）」。
分析时套用对应场景，把观察到的内容填进 `assets/analysis-form.md`。

---

## 0. 通用图 (General Image)
七要素（文章底 + 专业扩充）：
- **主体 Subject**：人/物/场景，身份、年龄、姿态、表情、服饰
  - 例：a young woman in red dress / 穿红裙的年轻女性
- **风格 Style**：写实/插画/3D/极简/赛博
  - 例：photorealistic / minimal vector
- **色彩 Color**：主色调、饱和度、对比
  - 例：warm amber palette, low saturation / 暖琥珀调，低饱和
- **光影 Lighting**：光源方向、软硬、时间
  - 例：soft side light, golden hour / 柔侧光，黄金时刻
- **构图 Composition**：景别、机位、三分/居中/对称
  - 例：close-up, eye level, rule of thirds
- **质感 Texture**：材质、表面、颗粒
  - 例：matte surface, subtle grain
- **氛围 Mood**：情绪、温度、叙事
  - 例：serene, intimate / 静谧，私密
- **分辨率 Resolution**：8k/高清/细节
  - 例：8k, ultra-detailed

## 1. 字体 / Logo
- **字形 Glyph**：衬线/无衬线/手写/复古
  - serif / sans-serif / handwritten / vintage
- **质感 Texture**：金属/霓虹/木质/玻璃/发光
  - metallic / neon glow / wood / glass / luminous
- **排版 Layout**：单字/单词/组合/间距
  - single letter / wordmark / monogram / wide tracking
- **配色 Palette**：渐变/单色/撞色
  - gradient / monochrome / complementary

## 2. 风景 / 场景 (Landscape)
- **前景 Foreground**：近处元素
  - rocks / flowers / silhouette
- **中景 Midground**：主体景物
  - mountain range / lake / city block
- **远景 Background**：山脉/天际/城市
  - distant peaks / skyline / horizon haze
- **时间光线 Time & Light**：黄金时刻/蓝调/正午/夜景
  - golden hour / blue hour / noon / night
- **氛围 Atmosphere**：雾/云/雨/通透
  - fog / clouds / rain / crisp clarity

## 3. 摄影 / 人像 (Portrait)
- **镜头焦段 Lens**：35/50/85mm，广角/长焦
  - 85mm portrait lens / wide-angle 24mm
- **光线 Light**：自然光/棚拍/逆光/伦勃朗
  - natural light / studio / backlit / Rembrandt
- **景深 DoF**：浅/深，虚化
  - shallow f/1.4 bokeh / deep focus
- **色调 Tone**：暖/冷/低饱和
  - warm / cool / desaturated
- **构图 Composition**：眼平/低角度/特写
  - eye level / low angle / close-up
- **后期 Post**：胶片模拟/磨皮/对比
  - film emulation / retouched / high contrast

## 4. 插画 / 二次元 (Illustration)
- **画风 Style**：赛璐璐/厚涂/水彩/像素
  - cel shading / thick paint / watercolor / pixel art
- **笔触 Brush**：干净/粗犷/柔边
  - clean lines / rough stroke / soft edge
- **色彩 Color**：高饱和/粉彩/撞色
  - vibrant / pastel / clashing
- **叙事 Narrative**：动态/静谧/剧情
  - dynamic action / quiet / storytelling

## 5. 产品 / 电商 (Product — 强推)
- **材质反光 Material**：金属/磨砂/玻璃/皮革，高光处理
  - brushed metal / matte / glass / leather, specular highlight
- **棚拍光 Studio Light**：柔光箱/顶光/边缘光
  - softbox key / top light / rim light
- **hero 角度 Angle**：45°/平视/俯拍，产品主导
  - 45-degree hero shot / flat lay / eye-level
- **背景过渡 Background**：纯色/渐变/环境融合
  - solid / seamless gradient / environmental
- **比例 Scale**：产品占画面比例，留白
  - product fills 70%, generous negative space

## 6. 美食 (Food — 强推)
- **蒸汽光泽 Steam & Sheen**：热气/酱汁反光/油光
  - rising steam / glossy sauce / oily sheen
- **视角 Angle**：顶视/45°/平视
  - top-down / 45-degree / eye-level
- **暖光 Warm Light**：窗光/暖灯，食欲感
  - window light / warm lamp, appetizing
- **质感 Texture**：酥脆/多汁/绵密
  - crispy / juicy / creamy
- **摆盘 Plating**：餐具/装饰/留白
  - tableware / garnish / minimal plating

## 7. 建筑 / 室内 (Architecture/Interior — 强推)
- **线条几何 Lines**：对称/透视/框架
  - symmetric / perspective / framing
- **光层次 Light Layers**：天光/人工光/阴影
  - skylight / artificial / shadow play
- **材质 Material**：混凝土/木/玻璃/金属
  - concrete / wood / glass / metal
- **空间纵深 Depth**：前景引导/层叠
  - leading lines / layered depth

## 8. 时尚 / 服装 (Fashion — 强推)
- **穿搭 Outfit**：层次/单品/配色
  - layered / statement piece / tonal
- **面料垂感 Fabric**：丝绸/牛仔/羊毛，动态
  - silk drape / denim / wool, flowing
- **姿势 Pose**：站/走/坐，动态
  - standing / walking / seated, dynamic
- **棚外景 Setting**：棚拍/街拍/自然
  - studio / street / natural
- **造型 Styling**：妆发/配饰
  - hair & makeup / accessories

## 9. 汽车 (Automotive — 强推)
- **车漆反光 Paint**：金属漆/哑光，环境反射
  - metallic flake / matte, environment reflection
- **轮毂细节 Wheel**：造型/高光
  - forged wheel, highlight
- **低角度 Low Angle**：贴地拍摄，力量感
  - ground-level, power stance
- **环境 Environment**：公路/城市/自然
  - highway / urban / nature
- **动感 Motion**：静止/行驶模糊
  - static / motion blur

## 10. 通用兜底 (Fallback)
主体 + 环境 + 光影 + 风格 + 技术参数（镜头/景深/分辨率）。

- **运动/健身**：动态、速度感、肌肉线条
